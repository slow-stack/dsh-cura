# release-notes/

这里放「某一版想用人话说明」的说明稿，文件名固定 `v<版本>.md`（例：`v0.9.1.md`）。

发版时 `.github/scripts/release-body.mjs` 会按 `package.json` 的版本号自动找这个文件：

- 第一行是 `# 标题` → Release 标题用它，其余内容进「本次变更」；
- 第一行不是标题 → 整份内容都进「本次变更」，标题仍是 `v<版本>`。

有这个文件就不再自动列提交。没有的话，正文会退化成「上一个 tag 到本 tag 的提交清单」。

格式建议（四段由脚本补齐，这里只写中间那段）：

```markdown
# v0.9.1 — 一句话说清这版是什么

## 生活关怀层不再绑在 QQ 上

说清为什么改、改完什么变了、不想用怎么退回去。

## 修掉一个会打崩整轮的问题

用户视角的现象 → 根因 → 现在的行为。
```

写给人看，不要写成 commit 列表。
